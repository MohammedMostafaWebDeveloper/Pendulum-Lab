# Pendulum Lab
An interactive pendulum simulation with many segments and plenty of customizations

# features
* Multi-segment pendulum simulation
* Adjustable gravity
* Adjustable air resistance
* Adjustable segment length and radius
* Points and screen dragging system
* Play/Pause controls
* Verlet integration based physics with constrains
* Grid background for clear coordinates

# Usage
This simulation is extremely useful for educational purposes or even experimenting for fun and discovering more about physics

# Controls
* Drag the sliders to adjust each parameter
* Click pause/play to pause or play the simulation
* Click the reset button to reset the simulation and parameters
* Left click and drag a point to move it around the screen
* Right click and drag the screen to move around the canvas
